# 次数に基づくラベル付けの形式化

## 1. 数学的設定

有限単純無向グラフ \(G=(V,E)\) を考え、頂点数を \(n\) とする。ラベル付けは
\[
f:V\longrightarrow\{0,\ldots,n-1\}
\]
という全単射である。頂点 \(v\) の次数を \(d(v)\)、近傍集合を \(N(v)\) と書く。

実数列 \(c_0<\cdots<c_{n-1}\) に対して、重み付き近傍和を
\[
S_v^{(c)}(f)=\sum_{u\in N(v)}c_{f(u)}
\]
で定める。ラベル付け \(f\) が次数順序を満たすとは、
\[
d(v)<d(w)\Longrightarrow f(w)<f(v)
\]
がすべての \(v,w\) について成り立つことである。また、同じ次数の頂点について
\[
d(v)=d(w),\ f(w)<f(v)\Longrightarrow
S_v^{(c)}(f)\leq S_w^{(c)}(f)
\]
が成り立つことを近傍和の順序条件と呼ぶ。

## 2. 主張

任意の有限単純無向グラフと任意の狭義単調増加実数列 \(c\) に対して、次数順序と
近傍和の順序条件を同時に満たすラベル付けが存在する。重みを
\(c_k=2^k\) とすれば、自然数の近傍和
\[
\sum_{u\in N(v)}2^{f(u)}
\]
について同じ結論が得られる。後者では、次数が等しく \(f(w)<f(v)\) ならば
\[
\sum_{u\in N(v)}2^{f(u)}
\leq
\sum_{u\in N(w)}2^{f(u)}
\]
である。

連結性、次数の上限、重みの正値性は仮定しない。空グラフおよび頂点を持つ辺なし
グラフも対象に含まれる。

## 3. 証明の構成

次数順序を満たすラベル付け全体を \(\mathcal A\) とする。頂点を次数の大きい順に
並べ、同じ次数の頂点を任意に並べて \(0,\ldots,n-1\) を割り当てれば、
\(\mathcal A\) は空でない。ラベル付けは有限個しかないので、各
\(g\in\mathcal A\) に対して
\[
\Phi(g)=\sum_{\{x,y\}\in E}c_{g(x)}c_{g(y)}
\]
を最小にする \(f\in\mathcal A\) を選べる。

\(d(v)=d(w)\) かつ \(f(w)<f(v)\) とする。次を置く。
\[
a=c_{f(v)},\qquad b=c_{f(w)},
\]
\[
A_v=\sum_{\substack{u\in N(v)\\u\ne w}}c_{f(u)},\qquad
A_w=\sum_{\substack{u\in N(w)\\u\ne v}}c_{f(u)}.
\]
狭義単調性から \(a>b\) が従う。\(v,w\) のラベルを交換したラベル付けを \(f'\) と
すると、次数が等しいため \(f'\) も \(\mathcal A\) に属する。

交換によるポテンシャルの差を計算するため、辺集合を次の四つの互いに素な類に
分ける。すなわち、\(v,w\) のいずれにも接続しない辺、\(v\) のみに接続する辺、
\(w\) のみに接続する辺、両方に接続する辺である。最後の類は \(v\) と \(w\) が
隣接するときの辺 \(\{v,w\}\) だけからなり、隣接しないときは空である。この辺の
寄与は交換の前後で \(ab\) と変わらない。したがって
\[
\Phi(f')-\Phi(f)=(a-b)(A_w-A_v)
\]
を得る。

\(f\) の最小性と \(a-b>0\) から \(A_v\leq A_w\) である。\(v,w\) が隣接する場合は
\[
S_v^{(c)}(f)=A_v+b,\qquad S_w^{(c)}(f)=A_w+a
\]
であり、隣接しない場合はそれぞれ \(A_v,A_w\) に等しい。いずれの場合も
\(S_v^{(c)}(f)\leq S_w^{(c)}(f)\) が成り立つ。

## 4. 形式化された内容

ラベル付け、重み付き近傍和、次数順序、辺ポテンシャルを定義し、次数順序を
満たすラベル付けの存在、ポテンシャルの最小値の存在、ラベル交換の恒等式、
最小化から近傍和の順序条件が従うことを証明している。辺ポテンシャルは無順序対
としての辺上で定義され、交換の計算では上記の四つの辺類を明示的に扱う。

狭義単調増加実数重みの場合の結論から、\(c_k=2^k\) を代入し、実数値の不等式を
自然数値の不等式へ移すことで、累乗重みの場合を得る。すべての公開定理は未証明の
穴を含まず、依存する公理の閉包は
\(\{\mathrm{propext},\mathrm{Classical.choice},\mathrm{Quot.sound}\}\)
に含まれる。この監査と公開定理の被覆は、定理ごとの公理出力を用いて確認する。
